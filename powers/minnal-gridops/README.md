# minnal-gridops power

Storm-restoration expertise for building agentic utility operations on AWS. Author: Yogesh Selvarajan · MIT.

**Install:** Kiro → Powers → Add Custom Power → From GitHub (repo URL, path `powers/minnal-gridops`) or From Local Path. Activates when you mention storm restoration, outages, crew dispatch, ETR, CAP alerts or cyclones.

| Component | Purpose |
|---|---|
| `skills/restoration-priority` | Ranking rules, hard constraints and properties to test |
| `skills/etr-estimation` | Honest restoration-time rules |
| `skills/cap-alert` | CAP 1.2 multilingual public alerts |
| `mcp.json` | Official AWS MCP servers: Amazon Location, Amazon Translate, Registry of Open Data (RODA) |
| `dev.kiro/steering` | ICS and safety conventions |
